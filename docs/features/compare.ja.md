# ポイント比較・熱量換算

メニューの **「比較」** をタップすると、現在プロットしているポイント（A〜I）のすべての状態値を一覧表で確認・比較できます。  
ダイアログはフローティング表示になっており、上部のハンドルをドラッグして空気線図の邪魔にならない位置へ動かしながら値を見比べられます。

![比較画面](../assets/images/ja/06_compare.png)

## 1. 一覧表で確認できる項目

初期状態では、登録されているすべてのポイントについて次の列が表示されます。

- **名称** (`name`)
- **温度** (`℃` / `℉`)
- **相対湿度** (`%`)
- **露点温度** (`℃` / `℉`)
- **絶対湿度** (`kg/kg(DA)` / `gr/lb(DA)`)
- **エンタルピー** (`kJ/kg` / `Btu/lb`)
- **湿球温度** (`℃` / `℉`)
- **比容積** (`m³/kg(DA)` / `ft³/lb(DA)`)

行の左端にあるドラッグハンドルを使って、**ポイントの並び順をドラッグ＆ドロップで入れ替える**こともできます。

## 2. 表示設定（歯車アイコン）：ポイント間の差分・項目調整

比較ダイアログ右上の **歯車アイコン（表示設定）** をタップすると、次のカスタマイズができます。

- **ポイント**: 一覧表に表示するポイント（A〜I）のチェックボックスをオン／オフします（チャートから削除せずに表だけ整理したいときに便利です）。
- **ポイント間**: 比較したい2点のペア（例：`A → B`）にチェックを入れると、表の下部に **2点間の差分（B − A）** が符号付き（`+` / `-`）で追加表示されます。
- **表示項目**: 列のチェックボックスで表示する項目を増減したり、ドラッグで表の列順を並び替えたりできます。

## 3. 単位換算（稲妻アイコン）：風量を加味した水分量・電力/熱量

比較ダイアログ右上の **稲妻アイコン（単位換算）** をタップすると、処理風量を使った実用的な負荷・加湿/除湿量の概算に切り替わります。

1. **「風量を加味する」** にチェックを入れます。
2. **「処理空気量 (m³/min)」** を入力します（例：`100`）。
3. 変換したい項目を選びます。
   - **絶対湿度→水分量**: 各ポイントおよびポイント間の水分量・加湿/除湿量を `kg/h` で表示します。
   - **エンタルピー**: 処理空気量あたりの熱負荷を **「電力」**（`kW`）または **「熱量」**（`kcal/h`）で表示します。

!!! note "換算の計算式（20℃標準空気密度ベース）"
    アプリ内部では、20℃の乾き空気密度 **1.2 kg/m³** を用いて次のように換算しています（`1 kW = 860 kcal/h`）。

    - **水分量 [kg/h]** ＝ 処理空気量 [m³/min] × 60 × 1.2 × 絶対湿度（または絶対湿度差）[kg/kg(DA)]
    - **電力 [kW]** ＝ 処理空気量 [m³/min] × 1.2 ÷ 60 × エンタルピー（またはエンタルピー差）[kJ/kg]
    - **熱量 [kcal/h]** ＝ 電力 [kW] × 860

具体的な計算例は [活用例](../examples.md) をご覧ください。
