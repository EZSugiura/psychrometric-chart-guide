# 保存と読込

作成した複数点（ポイントA〜I）のデータは、アプリ内の **スロット1〜9** の最大9件まで保存し、後から呼び出して再利用できます。

## データを保存する

![保存ダイアログ](../assets/images/ja/04_save_dialog.png)

1. メニューから **「保存」** をタップします。
2. **「保存データ一覧」** ドロップダウンから保存先のスロット（**スロット1〜スロット9**）を選択します。
3. **「ファイル名 File」** に任意の名称を入力します。
   - 何も入力せずに保存してもエラーにならず、現在の日時（例：`2026-11-19 15:30`）が自動で設定されます。
4. **「保存」** をタップします。

!!! note "無料版（Android）での保存について"
    無料プランでは、保存時に **「広告を視聴して保存しますか？」** という確認ダイアログが表示されます。**「広告を見て保存」** をタップしてリワード動画広告を最後まで視聴すると保存が確定します。  
    Pro プラン（月額・年額・買い切り・3日間パス）を購入済みの場合、および Web 版デスクトップの固定メニューパネルでは広告なしで即座に保存できます。

## 保存したデータを読み込む・削除する

![保存一覧](../assets/images/ja/05_slots_list.png)

1. メニューから **「読込」** をタップします（ポイントが1つもない状態でチャートをタップしたときのダイアログから **「読込」** を選んでも開けます）。
2. **「保存データ一覧」** にスロット1〜9が並びます（保存済みのスロットには登録ポイント数 `○ / 9` が表示されます）。
3. 読み込むスロットをタップすると、保存されていたポイントがチャートに復元されます。
4. 不要になったスロットは、右側のゴミ箱アイコンをタップし、確認ダイアログで **「削除」** を選ぶと消去できます。

## 画面をリセットする（「新規」）

メニューの **「新規」** をタップすると、現在チャート上にプロットしているポイントをすべて消去して白紙の状態に戻せます（未保存のデータがある場合は確認ダイアログが表示されます）。

!!! tip "単位系を切り替えても保存データはそのまま"
    保存データは内部的にメートル法（℃・kg/kg(DA)・kJ/kg）で保持されています。保存後に設定でヤード・ポンド法へ切り替えて読み込んでも、精度を保ったまま自動換算して表示されます。
