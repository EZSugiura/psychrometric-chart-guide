# 単位系と言語

メニューの **「設定」**（Web 版デスクトップの固定パネルでは歯車アイコン）から、表示単位系・表示言語・アカウント・サブスクリプションなどを変更できます。

![設定・単位](../assets/images/ja/07_settings_units.png)

## 1. 単位系の切り替え

**「単位系」** から次の2つをいつでも切り替えられます。

- **メートル法**（SI）
- **ヤード・ポンド法(米国)**（Imperial / US）

| 項目 | メートル法 | ヤード・ポンド法(米国) |
| --- | --- | --- |
| 温度・露点温度・湿球温度 | `℃` | `℉` |
| 絶対湿度 | `kg/kg(DA)` | `gr/lb(DA)`（1 lb = 7000 grains） |
| エンタルピー | `kJ/kg`（0℃基準） | `Btu/lb`（ASHRAE 0℉基準） |
| 比容積 | `m³/kg(DA)` | `ft³/lb(DA)` |
| 処理風量（空調シミュレーション） | `m³/h` | `CFM`（ft³/min） |
| 冷却能力（ピーク負荷・CSV） | `kW` | `RT`（米国冷凍トン） |
| 加熱・再熱負荷（ピーク負荷・CSV） | `kW` | `Btu/h` |
| 電力量・熱量（空調シミュレーション） | `kWh` | `kBtu` |
| 加湿量・除湿量・蒸気量 | `kg` | `lb` |
| ガス消費量（加熱熱源がガスの場合） | `m³` | `ft³` |

!!! note "保存データへの影響はありません"
    プロットや保存スロットのデータは、内部的には常にメートル法で保存されています。入力途中や保存後に単位系を切り替えても、自動換算されるためデータが壊れたりずれたりすることはありません。

!!! info "比エンタルピーの基準点の違い"
    メートル法（SI）は「0℃の乾き空気 = 0 kJ/kg」を基準とし、ヤード・ポンド法（ASHRAE IP）は「0℉の乾き空気 = 0 Btu/lb」を基準としているため、状態値そのものの変換には基準点のオフセット補正が適用されます。一方、許容幅（±）などの差分計算ではオフセットが相殺されるため純粋な倍率換算（1 Btu/lb = 2.326 kJ/kg）になります。

## 2. 言語の切り替え

**「言語」** ドロップダウンから **「端末の設定に従う」**、またはアプリが対応している **70以上の言語**（`ja`・`en` など）から表示言語を手動で選べます。

## 3. 設定画面にあるその他の項目

- **サブスクリプション**: 現在のプラン（`無料プラン` / 購読状態 / `3日間パス` の有効期限）、`プロフェッショナルにアップグレード`、`サブスクリプションを管理`、`購入を復元`、`Web版を開く(有料版限定)`、`Web版のリンクを共有`。
- **アカウント**: `Googleでサインイン`（Android 版で購入した Pro 権利を Web 版でも利用するための連携）。
- **お問い合わせ**・**プライバシーポリシー**・（対象地域のみ）**プライバシーオプション**・**データ提供元**（NASA POWER / GeoNames の帰属表示）。
