# 低温チャート

寒冷地条件、冷凍・冷蔵設備、冬季の極低温外気などを扱う場合、標準の空気線図（-10〜55℃）では点が左端や下端に張り付いて読み取りにくくなります。  
本アプリでは、無料版でも **「低温(-60〜20℃)」** のチャート範囲へ切り替えられます。

![低温チャート](../assets/images/ja/08_low_temp_chart.png)

## 1. チャート範囲の切り替え方法

1. メニューの **「チャート範囲」** をタップします（Pro 機能の「空調模擬」「空調シミュレーション」のメニュー内にも同じ項目があります）。
2. **「標準(-10〜55℃)」** または **「低温(-60〜20℃)」** を選び、**「OK」** をタップします。

選択した範囲は端末に保存され、次回起動時も維持されます。

## 2. 標準チャートと低温チャートの違い

| 項目 | 標準(-10〜55℃) | 低温(-60〜20℃) |
| --- | --- | --- |
| 温度軸（横軸） | `-10` 〜 `55 ℃` | `-60` 〜 `20 ℃` |
| 絶対湿度軸（縦軸） | 線形目盛（`0` 〜 `0.03295 kg/kg(DA)`） | **対数目盛**（`0.000005` 〜 `0.005 kg/kg(DA)`） |
| 0℃未満の飽和曲線 | 水面基準 | **氷面基準**の飽和水蒸気圧式 |
| 比エンタルピー線 | 正の領域 | マイナス領域を含む（`-60, -40, -20, 0, 20 kJ/kg`） |
| 相対湿度線 | 10%刻み等 | 10%未満は **1%刻み** で表示可能 |

### 対数目盛によるメリット
氷点下の空気は絶対湿度が非常に小さくなるため（例：-40℃飽和で約 `0.00008 kg/kg(DA)`）、通常の線形目盛では 0 の線に重なってしまいます。  
低温チャートでは縦軸を対数目盛にすることで、極低温域の湿度変化や露点・エンタルピーの関係を見やすくしています。

## 3. 範囲外ポイントの注意表示

すでに標準範囲（例：30℃・60%RH）でポイントをプロットした状態で低温チャート（-60〜20℃、上限絶対湿度 0.005 kg/kg(DA)）へ切り替えると、範囲外にあるポイントはチャート上に描画されません。  
このとき、チャート右上に **「範囲外のポイントがN件あります」** という通知バッジが表示され、ポイントが消えたのではなく表示範囲外にあることを確認できます。「標準(-10〜55℃)」へ戻すと再び描画されます。
