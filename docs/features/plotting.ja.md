# 複数点プロット・入力方法

本アプリでは、**ポイントA〜I の最大9点**を同じ空気線図上に同時にプロットできます。  
外気・還気・混合空気・コイル出口・室内など、複数の空気状態を並べて確認するのに便利です。

![複数点プロット](../assets/images/ja/03_multiple_points.png)

## 1. ポイントの追加・編集・削除

- **新しいポイントを追加**: グラフ上の空きエリアをタップすると、未使用のポイント（A → B → C …）の入力パネルが開きます。入力完了後に **「次のポイントを追加」** を押すと連続して登録できます。9個すべて使用済みの場合は「9個すべてのポイントを使用しています」と表示されます。
- **既存ポイントを編集**: チャート上のポイントマーカーの近くをタップすると、そのポイントの編集パネル（「ポイントを編集 - ポイントA」など）が開きます。
- **ポイントを削除**: 編集パネル右上のゴミ箱アイコンをタップし、確認ダイアログで **「削除」** を選びます。

## 2. 入力方法のバリエーション

### 自由入力（2つの状態値を指定）
入力パネルの2つのドロップダウンから、次の6種類より任意の2つを選んで数値を入力します。

- `温度`
- `相対湿度`
- `露点温度`
- `絶対湿度`
- `エンタルピー`
- `湿球温度`

!!! note "選択できない組み合わせ"
    **「露点温度」と「絶対湿度」** は実質同じ水蒸気分圧の情報を持つため、この2つだけの組み合わせは選択できません（片方を選ぶともう片方の選択肢から自動で除外されます）。また、既に数値を入力した状態でドロップダウンの項目を切り替えると、現在の空気状態を保ったまま新しい項目の値へ自動換算されます。

### `（グラフから）` 入力
各入力欄の下にある **「(グラフから)」** チェックボックスをオンにすると、その欄は手入力不可になり、**チャート上をタップまたはドラッグした位置からリアルタイムに値を読み取ります**。  
もう一方の入力欄に入力した値は固定したまま、グラフ上で感覚的に点の位置を決めたいときに便利です。

- パネルがフロート表示のときは、「(グラフから)」チェック中にパネルが自動で半透明になり、背後のチャートが見やすくなります。

### `拡張機能`（プロセスモード）
既に1つ以上ポイントが登録されている状態で2点目以降を追加する際、パネル上部の **「拡張機能」** ボタンをタップすると、既存ポイントを基準にした状態変化の入力モードに切り替わります（元に戻すときは **「自由入力」** をタップ）。

1. **一定に保つ状態値**（`温度` / `相対湿度` / `露点温度` / `絶対湿度` / `エンタルピー` / `湿球温度`）と、**基準にするポイント** を選びます。
2. 選択した状態値のロックされた値と、チャート上の赤い点線（基準値の等値線）が表示されます。
3. 変化させるもう1つの状態値を入力するか、「(グラフから)」で赤い点線上をなぞって位置を決定します。

これにより、たとえば「絶対湿度を一定にしたまま加熱する」「相対湿度を一定にしたまま温度を変える」といったプロセスを正確に作図できます。

## 3. 名称・プロット色・表示の調整

![点の入力パネル](../assets/images/ja/02_point_entry.png)

- **名称とプロット色**: 数値確定（**「OK」**）の次の画面で、任意の **「名称 Name」** と **「プロット色 Color」**（`緑`・`赤`・`オレンジ`・`黄`・`水色`・`青`・`紫`・`黒` の8色）を設定できます。
- **表示する線**: メニューの **「表示する線」** から、`相対湿度線`・`比エンタルピー線`・`比容積線`・`湿球温度線` の表示／非表示を個別に切り替えられます。
- **拡大／全体化**: 画面上部の **「拡大」**（または **「全体化」**）ボタンで、全体表示と縦横比 7:5 の拡大表示を切り替えられます。拡大中は2本指のピンチズームと、下端・右端のスクロールバーで移動でき、軸や等値線の目盛り数値も画面端に追従表示されます。
- **パネルの表示位置**: 入力パネル右上の切り替えアイコンで、フロート表示（ドラッグ移動可）と画面下部（縦画面時）／画面右（横画面時）への固定表示を切り替えられます。

!!! info "ポイント個別の表示・非表示について"
    メインの空気線図上でポイントを個別に一時非表示にするチェックボックスはありません（不要な点は編集画面のゴミ箱アイコンから削除します）。数値一覧表でのポイント別の表示／非表示は、[ポイント比較・熱量換算](compare.md) の「表示設定」（歯車アイコン）で行えます。
