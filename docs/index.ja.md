# 湿り空気線図（Psychrometric Chart）ガイド

温度・湿度を入力するだけで空気の状態点を空気線図上にプロットし、露点・絶対湿度・比エンタルピー・湿球温度・比容積を即座に確認できます。  
最大9点（ポイントA〜I）の比較や処理風量を加味した水分量・電力・熱量の概算、低温（-60〜20℃）チャート切替まで無料で利用可能です。  
さらに Pro 機能では、AHU（空調機）の機器別プロセス設計（空調模擬）や、実測気象データ（年間8,760時間）を使った年間空調シミュレーションにも対応しています。
