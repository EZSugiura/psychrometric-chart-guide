# よくある質問・お問い合わせ

## よくある質問（FAQ）

### 基本操作・プロットについて

??? question "アプリを開いたら真っ白なグラフだけで、どこから入力すればいいか分かりません"
    空気線図のグラフ上を**どこでもタップ**してください。「新規にポイントを入力するか、保存済みのデータを読み込んでください」と表示されるので、**「新規」** を選ぶと入力パネルが開きます。詳しい手順は [はじめての方へ（5分チュートリアル）](getting-started.md) をご覧ください。

??? question "「露点温度」と「絶対湿度」を同時に選べないのはなぜですか？"
    露点温度と絶対湿度はどちらも「空気中の水蒸気分圧」を別の表現で表したものであり、この2つだけでは空気の温度が決まらないためです。どちらかを「温度」「相対湿度」「エンタルピー」「湿球温度」のいずれかと組み合わせて入力してください。

??? question "ポイントを入力したのに、グラフから消えてしまいました"
    メニューの **「チャート範囲」** が **「低温(-60〜20℃)」** になっていませんか？選択中のチャート範囲（標準：-10〜55℃、低温：-60〜20℃・絶対湿度上限 0.005 kg/kg(DA)）の外側にあるポイントは描画されず、右上に「範囲外のポイントがN件あります」と表示されます。メニューの **「チャート範囲」** から **「標準(-10〜55℃)」** に戻すと再表示されます。

??? question "表示される単位を ℉ や gr/lb、Btu/lb に変えたいです"
    メニュー → **「設定」** の **「単位系」** で **「ヤード・ポンド法(米国)」** を選んでください。プロット済み・保存済みのデータも自動で換算されます。

### 保存・広告・Pro プランについて

??? question "無料版でデータを保存しようとすると広告の確認が出るのはなぜですか？"
    無料プラン（Android）では、ポイントデータのスロット保存時にリワード動画広告の視聴が必要です（広告を最後まで視聴すると保存されます）。Pro プラン（月額・年額・買い切り・3日間パス）を購入すると、バナー・起動時・保存時の広告がすべて非表示になります。

??? question "Android 版で Pro を買ったのに、Web 版で使えません"
    次の2点をご確認ください。

    1. Android 版アプリの **「設定」** → **「アカウント」** にある **「Googleでサインイン」** から Google アカウントでサインイン済みであること（購入権利をアカウントへ同期するために必要です）。
    2. [Web 版](https://psychrometric-chart-bdf76.web.app) に、Android 版でサインインしたのと **同じ Google アカウント** でサインインしていること。

??? question "端末を買い替えた・再インストールした後に Pro 権利を戻すには？"
    購入時と同じ Google Play アカウントで端末にログインした状態で、アプリ内の **「設定」**（または購入画面）にある **「購入を復元」** をタップしてください。

### 年間空調シミュレーション（Pro）について

??? question "都市検索で日本語の都市名を入力しても見つかりません"
    都市検索は **ローマ字（英語表記）** での検索に対応しています（例：`東京` → `Tokyo`、`大阪` → `Osaka`）。登録リストにない場所を指定したい場合は、**「緯度経度を直接入力」** または **「現在地から取得」** をご利用ください。

## お問い合わせ

アプリに関する不具合の報告・ご要望・ご質問は、アプリ内のお問い合わせフォームから送信できます。

1. 画面上部の **「メニュー」** → **「設定」** を開きます。
2. 下部にある **「お問い合わせ」** ボタンをタップします。
3. お問い合わせ種別・内容（必要であれば返信先メールアドレス）を入力して送信してください。

!!! note "Windows スタンドアロン版をご利用の場合"
    Windows 版では「お問い合わせ」を押すとメールアプリが起動します（宛先：`ez_games@ymail.ne.jp`）。
