# 空調シミュレーション（年間 8,760時間）

**空調シミュレーション**は、世界中の任意の地点について **1年分（8,760時間、うるう年は8,784時間）の実測気象データ** を取得し、混合・空調処理・一次エネルギー消費量を年間集計できる Pro 機能です。

メニューの **「空調シミュレーション」**（または画面上部の **「シミュレーション」** タブ）から開けます。

---

## ステップ 1：地点を選んで気象データを取得する

**「地点」** 画面では、次の3通りの方法で地点を指定できます。

1. **現在地から取得**（GPS）  
   端末の位置情報を取得し、最寄りの同梱都市のタイムゾーンを使ってデータを取得します（最寄り都市から 100 km 以上離れている場合はタイムゾーンが近似値になる旨の注意が表示されます）。
2. **都市を検索**  
   同梱されている都市データベース（GeoNames）から検索します。**「都市名をローマ字(英語表記)で入力してください」**（例：`Tokyo`, `Osaka`, `New York`）。
3. **緯度経度を直接入力**  
   スイッチをオンにして **緯度**・**経度** を数値入力します（この場合のタイムゾーンは UTC になります）。

続けて **「年」**（2001年〜現在まで選択可能）を選び、**「気象データを取得」** をタップします。  
NASA POWER の公開データセットから1時間刻みの気温・湿度データが取得され、取得完了後に **「プロットを見る」** をタップするとシミュレーション画面が開きます。

![気象データ取得](../assets/images/ja/11_weather_fetch.png)

!!! info "キャッシュと保存済みプロジェクト"
    - **キャッシュ済みの地点**: 取得した気象データは端末内に最大 20件（LRU方式）キャッシュされ、一覧からいつでも再読み込み・削除できます。
    - **保存済みプロジェクト**: 画面右上のフォルダアイコンから、フィルタ・セットポイント・AHU仕様まで含めて保存したプロジェクトを呼び出せます。

---

## ステップ 2：フィルタとプロットの色分けを見る

シミュレーション画面のメニュー（または画面右下の丸ボタン）から **「フィルタ」** を開くと、8,760時間の外気プロットを絞り込んで観察できます。

- **色分け**: **「月別」**（1〜12月を12色で表示）と **「セットポイント別」**（各セットポイントの色＋`非稼働` 灰色）を切り替えられます。
- **絞り込み条件**:
  - **月**: 1月〜12月のチップをタップして特定の月・季節のみ抽出
  - **時刻帯**: 0時〜23時のスライダーで営業時間帯などを抽出
  - **状態値の範囲**: 温度・相対湿度・絶対湿度・エンタルピーなどに最小／最大の範囲を追加
- 抽出条件に一致した時間数は **`{一致数} / {全時間数} 時間`** としてリアルタイムに表示されます。

![年間シミュレーション結果](../assets/images/ja/12_annual_simulation.png)

## ステップ 3：セットポイントを設定する

メニューまたは右下のボタンから **「セットポイント」** を開き、**「追加」** をタップして目標室内条件を登録します。

- **名前**・**プロット色**（8色）・**目標値**（任意の2つの状態値）を設定します。
- **許容幅**: 各状態値に `±` の許容幅を設定できます。許容枠はチャート上に描画され、混合空気がこの枠内に入っている時間は **「処理不要時間」** としてカウントされます（許容幅の組み合わせが矛盾して範囲が空になると警告アイコンが表示されます）。
- **適用条件**: 外気の温度や湿度範囲などで「このセットポイントを適用する条件」を絞れます。
- **優先順位**: セットポイントを複数登録した場合は、リストをドラッグして上下に並び替えられます。各時刻で上から順に条件を判定し、最初に一致したセットポイントが適用されます（どれにも一致しない時刻は **「非稼働時間」** になります）。

---

## ステップ 4：AHU 仕様を入力して年間シミュレーションを実行する

メニューまたは右下のボタンから **「AHU仕様/結果」** を開き、空調機の条件を入力します。

### 空調機仕様・エネルギー換算係数
| 項目 | 内容・既定値 |
| --- | --- |
| **処理風量** | 必須入力（メートル法：`m³/h`、米国単位：`CFM`） |
| **外気取入率** | `0%` 〜 `100%` のスライダー（還気はセットポイント中心状態とみなして混合点を算出） |
| **加熱熱源** | `蒸気` / `ガス` / `電気` |
| **加湿方式** | `蒸気式` / `気化式` / `なし` |
| **冷凍機COP** | 既定 `3.0` |
| **エネルギー換算係数** | 蒸気潜熱 `2100 kJ/kg`、ボイラー効率 `0.85`、ガス発熱量 `45 MJ/m³`、バーナー効率 `0.90`、電気ヒーター効率 `1.0` |

入力後、**「計算する」** をタップすると全時刻の計算が行われ、画面が結果表示位置まで自動でスクロールします。

### 結果の見方
- **年間合計**: `冷却電力量`（`kWh` / `kBtu`）と `冷却時間`、`加熱` と `加熱時間`、`再熱`、`加湿量`、`除湿量`、`非稼働時間`、`処理不要時間`
- **ピーク負荷**: `最大冷却負荷`（`kW` / `RT`）、`最大加熱負荷`（`kW` / `Btu/h`）
- **月別内訳**: 1月〜12月ごとの集計
- **セットポイント別**: 各セットポイントの `適用時間数` とエネルギー内訳

### 保存と CSV 出力
- **保存**: **「保存」** ボタンからプロジェクト名を付けて端末に保存できます（後から「保存済みプロジェクト」で復元可能）。
- **CSV出力**: **「CSV出力」** をタップすると、1時間ごとの全データ（**28列**：日時、外気状態7列、混合空気状態5列、セットポイント・状態区分、冷却/加熱/再熱負荷・加湿/除湿量・装置露点(ADP)・バイパスファクタ・警告、冷却電力量・加熱/再熱出力・単位・加湿使用量）を出力し、**「共有」** または **「端末に保存」** できます（※Web 版では「端末に保存」のみ利用できます）。
