# Pro プラン概要

空気線図プロッターの基本機能（複数点A〜I・保存/読込・比較・単位切替・低温チャート）はすべて無料で利用できます。  
教育・空調設計・エネルギー検討向けに、さらに高度な機能を使いたい場合は **Pro（プロフェッショナル）** へアップグレードできます。

## Pro で有効になる4つの特典

1. **広告非表示**  
   バナー広告・起動時広告・保存時のリワード動画広告がすべて非表示になります。
2. **空調模擬（AHU プロセス設計）**  
   プレヒーター・蒸気加湿・ワッシャー・冷水コイル・リヒーターの5機器を通過する空気の変化をリアルタイムに可視化・検証できます。  
   → 詳しくは [空調模擬（AHUプロセス設計）](ahu-design.md)
3. **空調シミュレーション（年間 8,760時間）**  
   世界中の都市・GPS現在地・緯度経度から1年分（8,760時間）の気象データを取得し、空調負荷や一次エネルギー消費量を年間・月別に集計し、CSV 出力できます。  
   → 詳しくは [空調シミュレーション（年間8760時間）](annual-simulation.md)
4. **Web 版でも使える**  
   Android 版で購入した Pro 権利を Google アカウントに連携すると、PC ブラウザから [Web 版](https://psychrometric-chart-bdf76.web.app) を利用できます（設定画面やメニューの **「Web版を開く(有料版限定)」** から開けます）。

!!! tip "Pro 版の画面レイアウト"
    Pro 権利が有効になると、アプリ上部のバーが **「プロッター」** と **「シミュレーション」** のタブ切り替えUIになり、プロッターと年間シミュレーションを素早く行き来できるようになります。

## 購入形態（4種類のプラン）

メニューの **「プロフェッショナルにアップグレード」**（または設定画面の **「プロフェッショナルにアップグレード」**）から、用途に合わせてプランを選べます。

| プラン | 特徴 |
| --- | --- |
| **月額** | 毎月自動更新のサブスクリプション |
| **年額** | 毎年自動更新のサブスクリプション |
| **買い切り(永久ライセンス)** | 一度の購入で継続利用できる永続ライセンス |
| **3日間パス** | 72時間（3日間）だけ試用・短期利用できるプリペイド型パス（自動更新なし） |

※ 価格は Google Play の表示（購入画面）をご確認ください。

## 購入の復元・サブスクリプション管理・Web 版連携

- **端末変更や再インストール時**: 設定画面または購入画面の **「購入を復元」** をタップしてください。
- **解約・管理**: Android 設定画面の **「サブスクリプションを管理」**（Google Play の定期購入管理画面）からいつでも確認・解約できます（3日間パスおよび買い切りは自動更新されません）。
- **Web 版で使う手順**:
  1. Android 版で Pro を購入します。
  2. Android 版の **「設定」** → **「アカウント」** にある **「Googleでサインイン」** から Google アカウントでサインインします。
  3. PC 等のブラウザで [Web 版](https://psychrometric-chart-bdf76.web.app) を開き、**同じ Google アカウント** でサインインします。
