# はじめての方へ（5分チュートリアル）

アプリを開いた直後は、まだ点が1つもない「白紙の空気線図」が表示されています。  
ここでは、例として **温度 25℃・相対湿度 50%** の空気をプロットし、値を確認して保存するまでの流れを説明します。

![メイン画面](assets/images/ja/01_home.png)

## ステップ 1：入力パネルを開く

1. 空気線図のグラフ上を**どこでもよいのでタップ**します。
2. まだ点が1つもない場合は、「新規にポイントを入力するか、保存済みのデータを読み込んでください」というダイアログが表示されます。
3. **「新規」** をタップします。画面上にポイント入力パネル（「ポイントする値を入力」）が開きます。

!!! tip "パネルの移動と固定"
    パネル上部のハンドルをドラッグすると好きな位置に動かせます。また、パネル右上の切り替えアイコンを押すと、画面下部（縦画面時）または画面右（横画面時）にレイアウト分割して固定できます。

## ステップ 2：温度と湿度を入力してプロットする

1. 1行目のドロップダウンが **「温度」** になっていることを確認し、数値欄に `25` と入力します。
2. 2行目のドロップダウンが **「相対湿度」** になっていることを確認し、数値欄に `50` と入力します。
   - 相対湿度以外にも、露点温度・絶対湿度・エンタルピー・湿球温度の任意の2項目から入力できます（詳細は[複数点プロット・入力方法](features/plotting.md)）。
3. **「OK」** をタップします。
4. 次の画面で **「名称 Name」**（例：`室内`）と **「プロット色 Color」**（8色から選択）を選び、**「OK」** をタップします。
5. チャート上に **ポイントA** がプロットされます。
   - 続けて別の点を入力する場合は **「次のポイントを追加」**、終了する場合は **「完了」** をタップします。

![点の入力パネル](assets/images/ja/02_point_entry.png)

## ステップ 3：計算された値の読み方

プロットされた点の詳しい数値を確認したいときは、画面右上の **「メニュー」** → **「比較」** をタップします。

25℃・50%RH の場合、一覧表にはおおよそ次の値が表示されます（標準大気圧 1013.25 hPa 基準）。

| 項目 | 計算値（目安） | 単位 |
| --- | --- | --- |
| 温度 | 25.0 | ℃ |
| 相対湿度 | 50.0 | % |
| 露点温度 | 13.9 | ℃ |
| 絶対湿度 | 0.010 | kg/kg(DA) |
| エンタルピー | 50.3 | kJ/kg |
| 湿球温度 | 17.8 | ℃ |
| 比容積 | 0.858 | m³/kg(DA) |

各指標の意味については [空気線図の読み方](reading-the-chart.md) をご覧ください。

!!! tip "ポイントの編集・削除"
    チャート上のポイント（例：A）の近くをタップすると、そのポイントの編集パネルが開きます。数値や色の変更、ゴミ箱アイコンからの削除ができます。

## ステップ 4：データを保存する

1. 画面右上の **「メニュー」** → **「保存」** をタップします。
2. **「保存データ一覧」** から保存先（**スロット1〜9**）を選びます。
3. **「ファイル名 File」** に分かりやすい名前（例：`夏期条件`）を入力します（未入力の場合は保存時の日時が自動で入ります）。
4. **「保存」** をタップします。
   - 無料プラン（Android）では「広告を視聴して保存しますか？」の確認ダイアログが表示されます。**「広告を見て保存」** を選んで動画広告を最後まで視聴すると保存が完了します（Pro プランでは広告なしで即座に保存されます）。

![保存ダイアログ](assets/images/ja/04_save_dialog.png)

保存したデータは、後から **「メニュー」** → **「読込」** でいつでも呼び出せます。
